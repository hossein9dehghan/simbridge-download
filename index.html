Install SimBridge

0.1.0 (14)

Android phone (with the SIM)

  1. Open this page on the Android phone and download the app. Android 10 or later.
  2. Open the file, allow installing from this source, and choose Install. Play Protect may warn about an app it does not know.
  3. Open SimBridge, grant what it asks, set its battery use to Unrestricted, then tap Pair an iPhone.
Download for Android

iPhone (iOS 26 or later)

  1. Set up SideStore once, following its own guide at sidestore.io. It signs apps with your Apple ID on the iPhone itself.
  2. Tap Add to SideStore, then install SimBridge there.
  3. Settings › Privacy & Security › Developer Mode must be on.
  4. Open SimBridge and scan the code on the Android phone.
Add to SideStore Add to AltStore IPA file

Good to know

  1. With a free Apple ID an app works for 7 days; SideStore renews it on the iPhone while it is on Wi-Fi.
  2. A separate Apple ID for this is the safer choice. Never give its password to anybody.
  3. Emergency calls: use a phone itself, never SimBridge.
  4. Check the files: SHA256SUMS.txt.

نصب SimBridge

0.1.0 (14)

گوشی اندروید (که سیم‌کارت دارد)

  1. این صفحه را روی گوشی اندروید باز کنید و برنامه را بگیرید. اندروید ۱۰ یا جدیدتر.
  2. فایل را باز کنید، نصب از این منبع را اجازه دهید و «نصب» را بزنید. ممکن است Play Protect درباره‌ی برنامه‌ی ناآشنا هشدار دهد.
  3. SimBridge را باز کنید، مجوزها را بدهید، باتری را «نامحدود» کنید و «Pair an iPhone» را بزنید.
دریافت برای اندروید

آیفون (iOS 26 یا جدیدتر)

  1. SideStore را یک بار طبق راهنمای خودش در sidestore.io راه بیندازید. برنامه را با Apple ID خودتان روی خود آیفون امضا می‌کند.
  2. «افزودن به SideStore» را بزنید و SimBridge را از همان‌جا نصب کنید.
  3. Settings › Privacy & Security › Developer Mode باید روشن باشد.
  4. SimBridge را باز کنید و کد روی گوشی اندروید را اسکن کنید.
افزودن به SideStore افزودن به AltStore فایل IPA

خوب است بدانید

  1. با Apple ID رایگان برنامه ۷ روز کار می‌کند؛ SideStore وقتی به Wi‑Fi وصل باشد روی خود آیفون تمدیدش می‌کند.
  2. Apple ID جدا امن‌تر است. رمزش را به هیچ‌کس ندهید.
  3. تماس اضطراری را از خود گوشی بگیرید، نه از SimBridge.
  4. درستی فایل‌ها: SHA256SUMS.txt
